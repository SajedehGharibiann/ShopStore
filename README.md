# E-Commerce React App

This is a front-end e-commerce application developed using React, Vite, and Redux Toolkit. It provides a seamless online shopping experience with features such as user authentication, product catalog browsing, and a functional shopping cart.

## Features

*   User Authentication:
    *   Login with password.
    *   Login with One-Time Password (OTP).
    *   Password Reset functionality.
*   Product Management:
    *   Browse a wide range of products with details.
    *   View products by category.
    *   Featured product sections (e.g., discounted products, main sliders).
*   State Management:
    *   Utilizes Redux Toolkit for efficient and predictable state management.
*   API Integration:
    *   Connects to a backend API for authentication, product data, and other services.
*   UI Components:
    *   Includes various reusable components for a dynamic and responsive user interface (Navbar, Footer, Product Cards, Sliders, etc.).
*   Form Handling:
    *   Custom hook (useFormFields) for managing form states and validation.
    *   Utility functions for notifications (notify.js).
    *   Data fetching utility (fetchData.js).
*   Configuration:
    *   Uses Vite for a fast development experience.
    *   Configurable API base URL via .env file.

## Technologies Used

*   Frontend: React, Vite
*   State Management: Redux Toolkit
*   Styling: CSS (with potential for CSS Modules or other styling solutions based on index.css)
*   API: fetch API (with a custom fetchData utility)
*   Utilities: axios (implied by common patterns, though not explicitly seen in the provided file list, fetchData.js is present), React Hooks.
